# Proposed 2.071 directions — awaiting a choice

No option below is implemented in 2.070.5. Game text will remain English and the existing Human and earlier layers will remain in use.

## A — Extend the fourth-period main-group table (recommended)

Add Gallium and Germanium to the existing eight-column main-group table, then extend toward As/Se/Br/Kr in later patches. Reuse workers, scientists, buildings, element decay, and levels. Give the two elements focused bonuses to later manual elements rather than another unrestricted Researcher exponent. Add a short sequence of Chemistry upgrades and element milestones, one reward at a time. This keeps the current main-group simplification; transition metals remain outside this table until separately designed.

## B — Deepen K/Ca before adding elements

Add Chemistry VI–VIII and a short progression through higher K/Ca levels. Use modest building/science rewards and extend full staffing to some third-period elements at a later Chemist milestone. This is the smallest format change, but provides less new discovery than option A.

## C — A small compound buyable section

Add two familiar compounds, such as KCl and CaCO3, in a Chemistry subtab. Reuse existing element amounts as costs and the game's original buyable format. Bonuses would target late Chemistry production, with clear next-unlock notes. This creates a new reason to allocate scientists, but adds more rules than A or B.

## Constraints for any selected direction

- Start from real near-end saves, including the 2.070.5 supplied save with about 6.82e33 Researchers.
- Do not use Researcher cost alone as the content gate: existing stockpiles could otherwise buy an entire release immediately.
- Validate both maximum useful-operation waits (normally at most 100 simulated seconds) and minimum numerical reward spacing using native production and purchases as soon as affordable.
- Preserve resources, purchased upgrades, manual staffing, and saved automation settings.
- Choose exact thresholds and effects only after native pacing tests; the proposals are not promises of untested numbers.
